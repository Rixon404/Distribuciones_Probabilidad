# Distribuciones de probabilidad

Aplicación web interactiva para explorar las distribuciones uniforme, binomial, hipergeométrica, Poisson y normal. Permite cambiar sus parámetros, consultar probabilidades de valores y rangos, y alternar entre la gráfica de probabilidad/densidad y la acumulada. Se puede usar desde computadora o móvil.

**Abrir la aplicación:** https://rixon404.github.io/Distribuciones_Probabilidad/
